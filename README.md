## 📱 การใช้งาน Web Server สำหรับจูน PID

1. เปิด **Serial Monitor** (ตั้งค่า Baud Rate เป็น `115200`)
2. กดปุ่ม `EN` (หรือ RST) บนบอร์ด ESP32 เพื่อรีเซ็ตการทำงาน
3. รอจนกว่าบอร์ดจะเชื่อมต่อ WiFi สำเร็จ ใน Serial Monitor จะแสดงหมายเลข **IP Address** (เช่น `192.168.1.55`)
4. เปิด Web Browser บนคอมพิวเตอร์หรือมือถือ (ที่เชื่อมต่อ WiFi วงเดียวกัน) แล้วพิมพ์ IP Address นั้น
5. กรอกค่า PID ที่ต้องการทดสอบ แล้วกดปุ่ม **Submit** บอร์ดจะทำการบันทึกค่าลง SPIFFS อัตโนมัติ

## ⚠️ ปัญหาที่พบบ่อย (Troubleshooting)

**1. บอร์ดรีเซ็ตตัวเองวนลูป (Boot Loop) / ขึ้น Error** **`[E][Wire.cpp:381] setClock(): could not acquire lock`**

* **สาเหตุ:** บอร์ด ESP32 หาเซ็นเซอร์ MPU6050 ไม่เจอ ทำให้การสื่อสาร I2C ล้มเหลว
* **วิธีแก้:** ตรวจสอบการต่อสาย SDA/SCL และไฟเลี้ยงของ MPU6050 ให้ถูกต้อง หากต้องการทดสอบรันเฉพาะ Web Server โดยยังไม่ต่อเซ็นเซอร์ ให้คอมเมนต์ (`//`) คำสั่ง `Wire.begin();` และคำสั่งอ่านค่าจากเซ็นเซอร์ในลูปทิ้งไปก่อน

**2. บอร์ดดับและรีเซ็ตตัวเองทันทีที่เชื่อมต่อ WiFi (ข้อความ** **`POWERON_RESET`****)**

* **สาเหตุ:** เกิดสภาวะไฟตก (Brownout) เนื่องจากโมดูล WiFi ของ ESP32 ดึงกระแสไฟกระชากสูงมากในจังหวะเชื่อมต่อ และพอร์ต USB จ่ายกระแสไฟไม่ทัน
* **วิธีแก้:** ใช้แบตเตอรี่ LiPo ต่อผ่านวงจรลดแรงดัน (Step-down 5V) จ่ายเข้าบอร์ดโดยตรง หรือจำกัดกำลังส่ง WiFi ในโค้ด `setup()` โดยเพิ่มคำสั่ง `WiFi.setTxPower(WIFI_POWER_8_5dBm);` ก่อนเรียก `WiFi.begin();`

**3. อ่านค่ารีซีฟเวอร์รวน หรือบอร์ดค้างเมื่อเป็นบอร์ดเปล่า**

* **สาเหตุ:** ขาที่ตั้งค่าไว้รับสัญญาณ PWM (ขา 34, 35, 32, 33, 25, 26) เกิดสถานะลอย (Floating) ทำให้จับคลื่นรบกวนในอากาศ และสั่งงาน Interrupt รัวๆ จนบอร์ดค้าง
* **วิธีแก้:** หากยังไม่ได้ต่อสายรีซีฟเวอร์ ให้คอมเมนต์คำสั่ง `attachInterrupt(...)` ใน `setup()` ไว้ก่อนจนกว่าจะต่อฮาร์ดแวร์ครบ
